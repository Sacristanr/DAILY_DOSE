# 🎓 TFC ASIR: Plataforma CDS & Proyecto Daily Dose

Bienvenido al repositorio oficial de nuestro Trabajo Final de Ciclo (TFC) del Grado Superior en Administración de Sistemas Informáticos en Red (ASIR). 

Este proyecto ha sido desarrollado de forma colaborativa y refleja un caso de uso real de consultoría y despliegue de sistemas, abarcando desde el diseño de la arquitectura hasta la implementación de la infraestructura en la nube, securización y puesta en producción.

## 📌 Sobre el Proyecto
El repositorio contiene toda la documentación técnica, bases de datos, diagramas de topología y el código fuente utilizado para el desarrollo y despliegue de la plataforma **CDS** y la infraestructura del cliente **Daily Dose**.

## 🛠️ Tecnologías y Entornos implementados
* **Cloud & Hosting:** Despliegue de instancias en AWS (Lightsail) con IP estática y certificados SSL/HTTPS.
* **Sistemas y Redes:** Diseño de topología de red, reglas perimetrales (VyOS) y arquitectura global.
* **Bases de Datos:** Modelado ER y despliegue de bases de datos MariaDB/SQL.
* **Desarrollo Web & CMS:** Implementación con WordPress, scripts en PHP, CSS personalizado y gestión de Custom Post Types (CPT).
* **Seguridad & Backups:** Políticas de roles de usuario, securización con Wordfence y automatización de copias de seguridad (UpdraftPlus / Snapshots de AWS).

## 📁 Estructura del Repositorio
* `01_MEMORIA` y `02_ANEXOS`: Documentación oficial, arquitectura y anexos técnicos.
* `03_BASES_DE_DATOS`: Scripts SQL, backups y modelos Entidad-Relación.
* `04_CODIGO_FUENTE_CDS`: Fragmentos PHP, CSS y configuraciones del sistema.
* `05_DIAGRAMAS`: Topologías de red, arquitecturas y diagramas de flujo.
* `07_EVIDENCIAS_PLATAFORMA_CDS`: Capturas de pruebas funcionales, seguridad y configuración en AWS.
* `08_VIDEO_DEMO_CDS` y `09_RESPOSITORIOS-CLIENTE`: Demostración audiovisual y manuales de usuario.
